# Marktstammdatenregister (MaStR) Datenmodell

Referenzdokumentation des
[MaStR](https://www.marktstammdatenregister.de/MaStR/Datendownload)
Gesamtdatenexports als [LinkML](https://linkml.io/)-Datenmodell.

## Direkt einsteigen

- **[Klassen](schema/index.md)** – alle Klassen des Datenmodells mit ihren Attributen
  (Einheiten, Anlagen, Marktakteure, Lokationen, Netze, …)
- **[Slots](schema/index.md#slots)** – alle Attribute im Überblick
- **[Enumerations](schema/index.md#enumerations)** – die Katalog-/Schlüsselwerte
- **[Types](schema/index.md#types)** – die verwendeten Datentypen

Die Referenzseiten werden direkt aus dem Schema in `linkml/mastr.yml`
generiert und sollten nicht von Hand bearbeitet werden. Details zum
Build-Prozess finden sich in der README des Repositorys.
